# Native ads brain (Tom Bell / Revenue Tactics)

Private library: public YouTube captions from [@revenuetactics](https://www.youtube.com/@revenuetactics), distilled into playbooks. Personal use. Not a republish of Tom’s paid course.

## Use on any device

**ChatGPT (strategy)**  
1. New Project.  
2. Paste `exports/chatgpt-project-instructions.md` into project instructions.  
3. Upload `exports/chatgpt-knowledge-pack.md`.  
4. Ask: “I’m at setup. This week’s list in order.”

**Claude (code)**  
1. New Project.  
2. Paste `exports/claude-coding-instructions.md`.  
3. Paste ChatGPT’s landing-page spec when you need HTML.

**This repo** is the master copy. After you change playbooks locally: commit, push, re-upload the knowledge pack to ChatGPT if it changed.

Do not upload all of `transcripts/` into ChatGPT. Use the knowledge pack; open a `{id}.txt` only when you need one video.
