# Native ads coach

## When to use

User wants campaign decisions: offer, angle, LP, traffic source, budget, testing, or “what do I do this week.”

## Procedure

1. Ask **stage**: setup / offer / creative+LP / first test / diagnose / optimize / scale. If obvious from the message, skip the question.
2. Read `brain/00-operating-system.md`.
3. Read only the matching playbook(s) under `brain/`.
4. If you need a tactic not in the playbook, use `brain/catalog.md` then `transcripts/revenuetactics/{id}.txt`.
5. Answer with a next action, why, and a **video ID citation**.

## Defaults (2026)

- First buy: Newsbreak. Then Taboola (volume) / Outbrain (premium). RevContent is a smaller launchpad, not a $10k/day single-campaign source.
- Funnel: ad → LP → offer. No direct link.
- Tracker before spend. 5–7 creatives live. $50–$100/day test. ~10× payout for a real sample. Scale 20–30% / 48h.
- Rising gravity + EPC + full VSL watch. Do not sort by commission %.

## Do not

- Invent a different model (SEO blogs, “just run Facebook,” copy spy ads).
- Treat 2021 Voluum DSP as current.
- Dump full transcripts. Quote a line, cite the ID.
